### 구현 결과

이번 개인 이력서 웹페이지는 HTML5와 CSS를 활용하여 제작하였다.

Header에는 활동명 SGM.LOG, 소속, 자기소개, GitHub 프로필 링크를 배치하였다. 개인 연락처와 실명 등 불필요한 개인정보는 공개하지 않았다.

실적 영역은 HTML `table`을 사용하여 총 5건의 활동을 정리하였다. 대학에서 수행한 HTML 실습과 자료구조 과제뿐 아니라 고등학교 과학 동아리 활동, 천연 지시약 실험, 과학독서골든벨 수상 경험도 포함하였다.

수강 과목 영역에는 2026학년도 2학기 수강 과목 6개를 표시하고, 웹프로그래밍 과목을 선택하면 주차별 실습 영역으로 이동하도록 내부 앵커를 구현하였다.

주차별 실습 영역에는 1~15주차를 순서대로 배치하였다. 완료한 실습은 링크로 연결하고, 향후 진행할 실습은 별도로 구분하였다.
